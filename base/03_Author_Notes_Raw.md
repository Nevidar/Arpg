## 1. Высокоуровневое видение

### Elevator Pitch
Темный арпг в славянском сеттинге, с крафтом

### Столпы
1. Глубокая кастомизация персонажа — огромное дерево пассивок, разнообразные моды которые по разному усиливают персонажа
2. Процедурные карты в endgame где планировка, монстры и модификаторы меняются каждый раз
3. Проверяем узкие места, чтобы не было дюпов
4. Очень развернутый и удобный аукцион
5. Любой убитый монстр потенциально может дропнуть что-то очень сильное. Должен быть элемент удачи и «это могло быть оно»
6. Action-боевая система. Бой должен быть динамичным, в реальном времени, с ощущением контроля и «веса» ударов

### Референсы
- Path of Exile — берём: ветку, частично систему сфер; не берём: сложные акты
- Hades / Hades 2 — берём: динамичность; не берём: уклонение
- Hero Siege — берём: рункрафт; не берём: сложные акты

### Аудитория
- Для кого: для тех кто готов разбираться, думаю 16+
- Хардкор: плавное повышение сложности на актах, на картах скейл сложности увеличивается
- Сессия: 5ч+

## 2. Core Loop

- Заходишь в зону / карту
- Убиваешь пачки монстров (основной экшен)
- Подбираешь лут (предметы, валюту, карты, механики лиги)
- Используешь то, что нашёл:
  - Надеваешь/крафтишь лучшую экипировку
  - Вставляешь/улучшаешь skill gems
  - Распределяешь очки в Passive Skill Tree
  - Улучшаешь карты (Alchemy, Chisel, Scarabs и т.д.)
- Становишься сильнее
- Идёшь в более сложный контент

(Как цикл меняется early/mid/end — не заполнено автором)

## 3. Боевая система

### Параметры
- Здоровье — предметы, ветка умений
- Сопротивления: огню / холоду / молнии / тьма / яд — предметы, ветка умений
- Урон — предметы, ветка умений
- Скорость передвижения — предметы, ветка умений
- Блок — предметы, ветка умений
- Уклонение — предметы, ветка умений

### Типы урона
Физический, Огонь, Холод, Молния, Яд / Тьма

### Формула
- Есть Increased и More: да
- Конверсия: сначала базовый flat → конверсия → потом % increased и more
- Проникновение: сопротивление противника минус проникновение
- Damage Taken у врагов: increased/reduced, more/less, по типу / Hits / DoT

### Криты
- Шанс = (базовый + добавочный) × (1 + сумма % increased Crit Chance)
- Атаки: с оружия; чары: с умения
- Базовый мультипликатор: 150%
- Урон крита = обычный урон × (150% + сумма +% Crit Multi)
- Lucky / Unlucky: нет

### Защита
- Броня / DR: да
- Сопротивления: да
- Уклонение / Блок / Dodge: да
- Energy Shield: нет
- Реген / Life Leech: да

### Скорость
- Атака: базовая + Increase
- Каст: базовая скорости чар способности + Increase
- Брейкпоинты: нет (плавная шкала)

## 4. Персонаж

### Класс (старт)
- Начнём с 1 класса — Воин
- Основная характеристика: сила
- Потом ловкость
- Самая низкая: интеллект
- Доп. ветка способностей на выбор:
  - Сплеш — атака перед собой по области
  - Выпад — атака перед собой, высокая дальность, прямоугольник
  - Множественные атаки — 4 раза подряд
  - Разрез — накладывает кровотечение
  - Удар по земле — урон вокруг себя

### Skills
- Окно всех способностей; уровни разблокировки: 1 / 4 / 8 / 12 / 16 / 24 / 30 / 36 / 50
- Дерево навыков: есть
- Свободная комбинация: да
- Support / модификаторы навыков: да, но не как в PoE

### Уровень
- Даёт силу / ловкость / инт
- Основной / доп / не осн: 1 / 0.6 / 0.3 (показываются только основные)
- Респек: будет
- Кап уровня: 100

## 5. Предметы

### База
- Оружие: меч, топор, двуручный топор, двуручный молот
- Броня: шлем, нагрудная броня, перчатки, сапоги, щит
- Аксессуары: кольца, амулет, спина (крылья, плащ)
- Расходники: зелье здоровья, зелье маны
- Валюта/крафт: золото, свитки заговоров (меняют свойства предметов)
- «Кости с чертой», «дощечка с резой», черепа и т.д. — как руны в Diablo; комбинации дают особые предметы

### Редкость
- Обычный — база, без свойств
- Магический — 1 суфф или 1 преф
- Редкий — до 3 суфф и до 3 преф
- Уникальный — до 4 суфф и до 4 преф; фиксированные статы, нельзя крутить как rare/magic
- Неблагословлённый → после особого квеста получает благословение, усиливает характеристики
- Проклятый — сильные бонусы + сильные дебафы (пример: +100% more damage, но −90% HP)

### Аффиксы
- Кол-во по редкости
- Префиксы и суффиксы: есть
- Тиры: T1 = 100% силы мода, T9 = 1%

### Крафт
- Глубина скорее как PoE
- Разные способы изменения предметов
- Рункрафт как Hero Siege / Diablo: определённый набор вставок → новый более сильный предмет

### Сеты / уникалы
- Сетов нет
- Уникалы: сильные и слабые, зависят от уровня и самого предмета

## 8. Сложность

### Кривая
- Уровни локаций
- ~3–5 актов на старте
- ~1 уровень персонажа на локацию акта
- Уровень локации +1 на каждой следующей
- Монстры: прибавка HP/урона за уровень (баланс позже)
- Случайные моды монстров: статы и возможно способности

### Смерть
- Потеря опыта: до конца актов 0%, после 10%
- Потеря предметов: нет

### Баланс билдов
- Баланс по дороге
- Сила сильно зависит от вложения золота в билд (= больше гринда)
