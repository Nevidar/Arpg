# Arpg / Nevidar

Тёмный славянский ARPG на **Godot 4.7**.

## Быстрый старт

См. `HOW_TO_RUN.md` — открыть проект в Godot и нажать F5.

## Документы

- `00_PROGRESS.md` — **трекер прогресса** (читать первым)
- `01_ARPG_Design_Template.md` — дизайн-документ
- `02_Slavic_Mythology_Lore.md` — лор
- `03_Author_Notes_Raw.md` — сырые заметки автора
- `MVP-plan.txt` — план MVP
- `04_Inventory_Design.md` — референсы инвентаря PoE / Diablo / Hero Siege
- `base/` — **замороженный снимок доков, не редактировать**

## Код

- `scenes/` — арена, игрок, враг
- `scripts/` — бой, игрок, враги
