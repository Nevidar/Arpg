# Славянская мифология — Лор для ARPG

**Версия:** 0.1  
**Статус:** Черновик для проекта

Этот файл содержит собранный материал по славянским богам, добрым/нейтральным существам и враждебным монстрам.  
Использовать как основу для лора, врагов, покровителей классов и атмосферы игры.

---

## 1. Главные боги

| Бог / Богиня | Сфера влияния | Характер | Игровой потенциал |
|--------------|---------------|----------|-------------------|
| **Перун** | Гром, молния, война, порядок, княжеская власть | Грозный, справедливый, воинственный | Покровитель воинов, берсерков, паладинов. Тема порядка против хаоса |
| **Велес (Волос)** | Скот, богатство, магия, подземный мир, поэзия, клятвы | Хитрый, мудрый, двойственный | Покровитель магов, некромантов, торговцев, плутов. Связь с Навью |
| **Мокошь (Макошь)** | Земля, плодородие, прядение, ткачество, судьба | Заботливая, но строгая | Покровительница ремесленников, ведьм, тех, кто работает с судьбой и крафтом |
| **Сварог** | Небесный огонь, кузнечество, порядок, творение | Созидательный | Покровитель кузнецов, создателей, тех, кто работает с огнём и порядком |
| **Дажьбог** | Солнце, свет, достаток, дарование благ | Щедрый | Покровитель светлых билдов, поддержки, тех, кто даёт силу другим |
| **Стрибог** | Ветры, воздух, атмосфера | Стихийный | Покровитель воздушных/скоростных билдов |
| **Род** | Род, судьба, рождение, предки | Творящий | Верховная сила судьбы и крови. Хорош для системы наследия/предков |
| **Ярило** | Весна, плодородие, юная сила, страсть | Буйный, жизнерадостный | Тема возрождения, ярости, жизненной силы |

**Важный конфликт:** Перун (Небо / Порядок) ↔ Велес (Земля / Навь / Хаос).  
Это отличная основа для центрального конфликта мира.

## 2. Другие важные божества

| Имя | Сфера | Примечание |
|-----|-------|----------|
| **Рожаницы** | Судьба новорождённого | Определяют «долю» человека |
| **Мать — Сыра Земля** | Живая земля | Священная сила, а не классическая богиня |
| **Святовит** | Война, победа, пророчества | Особенно силён у западных славян |
| **Сварожич** | Огонь (жертвенный и домашний) | Связь с домашним очагом и ритуалами |
| **Белобог** | Свет, добро, порядок | Поздняя дуалистическая фигура (против Чернобога) |
| **Морена / Марена** | Смерть, зима | Может быть как богиней, так и враждебной силой |

## 3. Добрые и нейтральные существа

### Домашние духи (в основном доброжелательные)

| Существо | Описание | Характер в игре |
|---------|----------|-----------------|
| **Домовой** | Хозяин и хранитель дома | Добрый, если дом в порядке. Может давать баффы, предупреждать об опасности или быть квестовым духом |
| **Дворовой** | Дух двора и скота | Нейтральный защитник хозяйства |
| **Овинник** | Дух овина | Строгий, но не злобный |
| **Банник** | Дух бани | Самый вспыльчивый. Может быть опасным мини-боссом или нейтральным, если соблюдать правила |
| **Домашняя змея / Стопан** | Дух-хранитель в образе змеи | Приносит удачу, если не трогать |

### Природные и защитные духи

| Существо | Описание | Характер в игре |
|---------|----------|-----------------|
| **Леший** | Хозяин леса | Нейтральный. Может помогать или вредить в зависимости от поведения игрока в лесу |
| **Берегиня** | Древний защитный женский дух | Одна из самых положительных фигур. Хороший кандидат на союзника/покровителя |
| **Вила** | Прекрасные женские духи природы (южнославянские) | Могут быть помощницами достойным |
| **Чур / Щур** | Дух предка, охранитель границ | Защитный. Формула «Чур меня!» может стать игровой механикой защиты |

### Мифические птицы

| Существо | Описание | Характер |
|---------|----------|----------|
| **Алконост** | Птица радости | Светлая, добрая |
| **Гамаюн** | Вещая птица | Мудрая, нейтральная, знает будущее |
| **Сирин** | Птица с женским лицом | Более двойственная |
| **Жар-птица** | Огненная волшебная птица | Источник чудес и одновременно опасности |

## 4. Враждебные существа (для боевой системы)

### Обычные монстры

- **Упырь / Вурдалак** — восставший мертвец, пьёт кровь
- **Волколак** — оборотень
- **Русалка / Мавка** — дух утопленницы
- **Кикимора** — злобный домашний/болотный дух
- **Чёрт / Бес / Анчутка** — мелкая нечисть
- **Навь / Заложный покойник** — дух «неправильного» покойника
- **Полудница** — дух полуденного зноя
- **Болотник** — хозяин болота
- **Злыдни** — мелкие духи несчастий
- **Лихорадки (Трясовицы)** — духи болезней
- **Бабай** — ночной дух, пугающий/убирающий
- **Ночница** — душит спящих
- **Дрекавац** — дух мертворождённого (южнославянский)

### Сильные / элитные

- **Леший** (в враждебной версии)
- **Водяной**
- **Вий** — хтоническое существо, убивающее взглядом
- **Баба-яга** (в злой версии)
- **Аждая / Змей**
- **Полевик**
- **Лихо Одноглазое**

### Потенциальные боссы

| Существо | Уровень | Потенциал |
|---------|---------|-----------|
| **Змей Горыныч** | Средний / Высокий | Классический многоголовый дракон |
| **Кощей Бессмертный** | Высокий / Сюжетный | Смерть спрятана отдельно — отличная механика босса |
| **Баба-яга** (усиленная) | Средний / Высокий | Может быть и боссом, и испытанием |
| **Вий** | Высокий | Уникальная механика взгляда |
| **Чудо-Юдо** | Средний / Высокий | Водное чудовище |
| **Морена** | Высокий / Сюжетный | Воплощение смерти и зимы |
| **Чернобог** | Высший | Если использовать дуалистическую трактовку |

## 5. Ключевые темы для лора игры

Рекомендуемые центральные идеи:

1. **Конфликт Перуна и Велеса** — Небо/Порядок против Земли/Нави/Хаоса.
2. **Навь** — мир мёртвых и «неправильных» покойников, который просачивается в явь.
3. **Цена силы** — любая большая сила требует жертвы или сделки.
4. **Уважение к границам** — лес, вода, дом, могила. Кто нарушает правила — становится добычей.
5. **Род и Доля** — судьба, кровь, предки имеют реальное влияние.

## 6. Как использовать в игре

- **Покровители классов/билдов:** Перун, Велес, Мокошь, Дажьбог, Сварог.
- **Духи локаций:** Леший (лес), Водяной (водоёмы), Домовой (дома/убежища), Банник (бани как особые зоны).
- **Система порчи/Нави:** Упыри, Навьи, Заложные покойники, влияние Велеса и Морены.
- **Нейтральные NPC/квестодатели:** Домовые, Берегини, Гамаюн, уважаемые Лешие.
