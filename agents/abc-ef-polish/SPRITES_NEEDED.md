# Список нужных спрайтов — Nevidar

Сейчас всё на цветных `Polygon2D`. Ниже — что рисовать, чтобы заменить прототип.

Стиль: тёмный славянский фэнтези, top-down (или лёгкая изометрия 3/4), читаемые силуэты, без кислотного неона.

---

## 1. Персонаж (Воин)

| Ассет | Кадры / варианты | Примечание |
|-------|------------------|------------|
| Тело idle | 4–6 | без оружия / с оружием |
| Ходьба 8 направлений | 6–8 на направление | или 4 направления × зеркало |
| Атака (ЛКМ) | 4–6 | дуга удара |
| Splash (Q) | 4–6 | широкий замах |
| Ground slam (E) | 5–7 | удар в землю + пыль |
| Рывок | 3–4 | шлейф |
| Получение урона / смерть | 3 + 5 | |
| Тень под ногами | 1 | общая |

**Экип (слои поверх тела):** оружие, шлем, нагрудник, щит, перчатки, сапоги — хотя бы 1 «простой» + 1 «дорогой» сет на слот.

---

## 2. Враги

На каждый тип: idle, walk (4 напр.), attack, death. Палитра разная.

| Тип | Референс |
|-----|----------|
| Обычный | серый/коричневый нежить / разбойник |
| Быстрый | худой, рыжий/оранжевый |
| Танк | массивный, фиолетово-серый |
| Дальний | сине-серый, лук/плевок |
| Чемпион | золотая аура / рога / метка |
| Редкий | фиолетовая аура |
| Боссы актов | **Лихо**, **Водяной**, **Воевода**, **Аждая** (змей), **Морена** — уникальный спрайт + 2–3 атаки |
| Убер | **Тень Морены** — крупнее, холод/тьма |

Снаряд дальника: 1–2 кадра (кость / капля / стрела).

---

## 3. Локации / тайлы (по актам)

Плитки пола + 6–12 пропов на акт. Размер тайла удобный: 64×64 или 48×48.

| Акт | Пол | Пропы |
|-----|-----|-------|
| 1 Деревня/лес | трава, грязь, тропа | пень, ель, изба, забор, камень |
| 2 Болота | вода/тина, кочки | камыш, топь, кости, топляк |
| 3 Город | брусчатка, грязь улиц | дом, навес, бочка, фонарь, стена |
| 4 Велес | степь, курган | идол, курган, сухая трава, череп скота |
| 5 Зима/Навь | снег, лёд, чёрная земля | ледяной шип, врата, руна, мёртвое дерево |
| Хаб | дерево/камень двора | алтарь карт, прилавок купца, костёр |
| Карты эндгейма | реюз актов + 1 уникальный проп на карту | |

**Переходы:** арка/ворота выхода, портал (анимация 4–6 кадров), стрелка/маркер выхода.

## 6. Техзаметки для Godot

- Экспорт: PNG, прозрачность, trim + atlas  
- Именование: `char_warrior_walk_e_01.png`, `enemy_fast_attack_01.png`, `tile_act1_grass_01.png`  
- Папка: `res://assets/sprites/...` (создать, когда появятся файлы)  
- Пока в игре — `Polygon2D`; подмена через смену `texture` у `Sprite2D`/`AnimatedSprite2D`
